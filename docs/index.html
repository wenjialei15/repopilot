命令行工作流

从扫描到发版检查

scan

运行 15 条可配置检查，获取 JSON、Markdown 或终端报告。

plan

把失败项整理成维护任务，给出优先级、依据和验收条件。

diff

比较两份扫描报告，区分新增、已修复和待复核的问题。

release-check

核对文档、测试配置和可观测的 CI 结果，列出阻断项和证据缺口。

快速开始

下载并扫描

需要 Python 3.11 或更新版本。下载 wheel 后，在文件所在目录执行以下命令。

下载 wheel 源码包 SHA-256 校验和
Shell
python -m pip install ./repopilot_health-0.1.0-py3-none-any.whl
repopilot --version
repopilot scan . --format terminal
